AND + XOR → NOT, OR, and a Full Adder

1) What a gate does

A gate takes bits in and gives a bit out.

AND
Only turns on when 1 and 1 are both present.
XOR
Turns on when the inputs are different: 0/1 or 1/0.

3) NOT from XOR

If you have a constant 1, XOR flips the bit.

0 = off, 1 = on
NOT A = A XOR 1
Input A: 0
Constant 1: 1
Output: 1

When A = 0, XOR with 1 gives 1. When A = 1, XOR with 1 gives 0.

4) OR from AND + XOR

There is a neat trick:

A OR B = (A XOR B) XOR (A AND B)
A: 0
B: 0
A XOR B: 0
A AND B: 0
Output OR: 0

This works because XOR gives the "one is on" cases, and AND adds the "both are on" case.

6) Full adder

A full adder adds three bits: A, B, and Carry-In.

X1 = A XOR B C1 = A AND B Sum = X1 XOR Cin C2 = X1 AND Cin CarryOut = C1 OR C2

First add A and B. Then add the carry-in. Finally, combine the two possible carries.

A: 0
B: 0
Cin: 0
X1 = A XOR B → 0
C1 = A AND B → 0
Sum = X1 XOR Cin → 0
C2 = X1 AND Cin → 0
CarryOut = C1 OR C2 → 0

8) Big picture

The same idea repeats many times:

Half adder + carry handling → Full adder Full adder + full adder + full adder → 4-bit adder 4-bit adder + more stages → 8-bit, 16-bit, 32-bit, 64-bit adders

Once you understand this page, you understand the basic logic behind arithmetic inside a CPU.
